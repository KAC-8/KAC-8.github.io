Privacy Policy — English

We collect only the data needed to operate KAC8 features on Discord. By inviting or using the bot, you consent to this Privacy Policy and Discord's data rules.

Data Collection

  • User and Guild IDs: captured to identify servers, members, and permissions.
  • Profile metadata: usernames, avatars, and roles as exposed by Discord for display and eligibility.
  • Interaction logs: command triggers, cooldowns, and moderation actions for audit and abuse prevention.
  • Configuration: leveling settings, automations, language preferences, and feature toggles you set.

Data Usage

  • Deliver leveling, achievements, and dashboards tailored to your server's stored settings.
  • Calculate XP and ranks using stored IDs; no message content is stored for leveling.
  • Honor server preferences for localization, moderation thresholds, and notification styles.
  • Security and reliability: logs help detect spam, raiding, and platform abuse.

Data Security

  • Data is stored in MongoDB with encryption at rest; connections use TLS in transit.
  • Access to databases and dashboards is restricted to authorized KAC8 operators.
  • Backups are encrypted and retained only for continuity; old backups are purged on schedule.
  • We respond promptly to deletion requests for server configurations or user data where feasible.

Retention & Control

  • Server settings are retained while KAC8 remains in your server; removal triggers cleanup.
  • Basic logs are kept temporarily for diagnostics and anti-abuse, then anonymized or deleted.
  • Submit requests to view or erase data through the dashboard or the official KAC8 Discord contact.
العربية

سياسة الخصوصية — العربية

نجمع فقط البيانات اللازمة لتشغيل ميزات KAC8 على ديسكورد. بدعوة البوت أو استخدامه، فإنك توافق على سياسة الخصوصية هذه وعلى قواعد بيانات ديسكورد.

جمع البيانات

  • معرفات المستخدم والخادم: لحفظ هوية الخوادم والأعضاء والصلاحيات.
  • بيانات العرض: الأسماء والصور والأدوار المتاحة من ديسكورد لعرضها واختيار الصلاحيات.
  • سجلات التفاعل: استدعاء الأوامر، أزمنة الانتظار، وإجراءات الضبط للتدقيق ومنع الإساءة.
  • الإعدادات: تهيئة مستويات الخبرة، الأتمتة، تفضيلات اللغة، وخيارات الميزات التي تحددها.

استخدام البيانات

  • تقديم نظام المستويات والإنجازات واللوحات بناءً على إعدادات خادمك المخزنة.
  • حساب الخبرة والترتيب باستخدام المعرفات فقط؛ لا يتم تخزين محتوى الرسائل لأغراض المستوى.
  • الالتزام بتفضيلات الخادم للغة وضوابط الإشراف وأنماط التنبيه.
  • الأمان والموثوقية: تساعد السجلات في اكتشاف السبام أو الغارات أو إساءة استخدام المنصة.

أمان البيانات

  • يتم تخزين البيانات في MongoDB مع تشفير أثناء السكون، وتُؤمَّن الاتصالات عبر TLS أثناء النقل.
  • يقتصر الوصول إلى قواعد البيانات واللوحات على مشغلي KAC8 المصرح لهم فقط.
  • يتم تشفير النسخ الاحتياطية والاحتفاظ بها لضمان الاستمرارية، ويتم حذف النسخ القديمة بانتظام.
  • نستجيب بسرعة لطلبات الحذف لإعدادات الخادم أو بيانات المستخدم متى أمكن ذلك.

الاحتفاظ والتحكم

  • يتم الاحتفاظ بإعدادات الخادم طالما أن KAC8 موجود في خادمك؛ الإزالة تؤدي إلى التنظيف.
  • يتم الاحتفاظ بالسجلات الأساسية مؤقتًا لأغراض التشخيص ومكافحة الإساءة ثم تُزال أو تُنزع الهوية.
  • يمكنك طلب عرض البيانات أو حذفها عبر لوحة التحكم أو التواصل مع فريق KAC8 على ديسكورد.
